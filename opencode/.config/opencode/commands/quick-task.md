---
description: "Run a lightweight approved workflow for a small task"
---

Use the quick-task-workflow skill.

Arguments:
- Task prompt: all arguments

Run a lightweight workflow for the provided task:
1. Confirm the task is small and bounded.
2. Clarify only blocking ambiguity.
3. Write a short inline spec and 2-5 step plan.
4. Wait for approval.
5. Implement the full approved task.
6. Verify with the smallest relevant command.
7. Ask permission before staging or committing only the intended paths in an atomic conventional commit.
