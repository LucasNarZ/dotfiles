---
description: "Create a tailored resume HTML file from a job description"
---

Leia o `AGENTS.md` do diretorio atual antes de executar esta tarefa.
Use o workflow da skill `quick-task-workflow`.

Arguments:
- Descricao da vaga: all arguments

Crie um curriculo personalizado para a vaga informada:
1. Extraia o nome da empresa a partir da descricao da vaga.
2. Crie um arquivo `{nome_empresa}.html`, usando o nome da empresa em minusculas e kebab-case.
3. Use a descricao da vaga como base para adaptar o conteudo do curriculo.
4. Entregue um HTML completo, pronto para abrir no navegador.
